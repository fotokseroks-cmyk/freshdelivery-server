FRESHDELIVERY — КОМПЛЕКТ «ПОСЕТИТЕЛИ» (одним архивом)
=====================================================

ЧТО ВНУТРИ
----------
1-Сайт-на-Netlify/
    index.html   — ваш сайт (готов, менять ничего не нужно)
    visitor.js   — скрипт-сигнальщик (кладётся рядом с index.html)

2-Сервер-на-GitHub-и-Render/
    server.js    — сервер приёма сигналов + защита админки
    package.json — паспорт проекта для Render
    public/
        admin.html — админка (сервер отдаёт её сам, на Netlify НЕ загружать)

ПОЧЕМУ ДВА ХОСТИНГА
-------------------
Netlify отдаёт только статичные файлы и не умеет запускать server.js.
Поэтому: сайт живёт на Netlify, сервер с админкой — на Render.
Они дружат через CORS — он уже настроен в server.js, отдельно ничего включать не нужно.

УСТАНОВКА ПО ШАГАМ
------------------
ШАГ 1. GitHub
  1) Зайдите на github.com (если нет аккаунта — Sign up: почта + пароль).
  2) Нажмите New repository. Имя: freshdelivery-server. Выберите Public.
     Галочку «Add a README» НЕ ставьте. Create repository.
  3) На странице репозитория нажмите «uploading an existing file».
  4) Перетащите ДВА файла из папки 2-Сервер-на-GitHub-и-Render:
     server.js и package.json.
     Файл admin.html в GitHub НЕ загружайте — он уже лежит в папке public/ рядом
     с ними, если вы загружаете всю папку целиком; можно загрузить всю папку
     2-Сервер-на-GitHub-и-Render со всем содержимым.
  5) Commit changes.

ШАГ 2. Render (сервер)
  1) Зайдите на render.com, войдите через Sign in with GitHub.
  2) New -> Web Service -> выберите freshdelivery-server (при необходимости
     разрешите доступ к репозиторию).
  3) Поля:
     Name: freshdelivery-server (или своё)
     Start Command: node server.js
     Instance Type: Free
  4) Create Web Service. Через 1-3 минуты статус станет Live.
  5) Вверху появится адрес вида https://freshdelivery-server-xxxx.onrender.com
     СКОПИРУЙТЕ ЕГО — он понадобится в шаге 3.

ШАГ 3. Впишите адрес сервера в два файла
  1) Откройте в Блокноте visitor.js (из папки 1-Сайт-на-Netlify).
  2) Найдите строку: var SERVER = 'https://ПОМЕНЯЙТЕ-НА-АДРЕС-СЕРВЕРА.onrender.com';
  3) Замените адрес на ваш с Render. Кавычки не трогайте. Сохраните.
  4) Откройте admin.html (из папки 2-Сервер-.../public) и сделайте то же самое
     со строкой var SERVER = '...'; Сохраните.
  5) visitor.js перезалейте на GitHub? НЕТ — visitor.js относится к сайту,
     поэтому изменения нужны только в вашей локальной копии для Netlify.
     А admin.html с новым адресом перезалейте в GitHub (папка public/),
     иначе админка не узнает адрес сервера.

ШАГ 4. Netlify (сайт)
  1) Соберите папку для сайта: index.html + visitor.js (из папки 1-Сайт-на-Netlify).
  2) Перетяните её на Netlify как обычно (app.netlify.com -> Drag and drop).
  3) Сайт перезальётся сам.

ШАГ 5. Админка
  Откройте в браузере: ваш-адрес.onrender.com/admin.html?key=fresh2026
  Если сервер «проснулся» — первый вход может занять 30-60 секунд, это нормально.

ПАРОЛЬ АДМИНКИ
--------------

и впишите свой пароль. Тот же пароль впишите в admin.html в строку

Перезалейте оба файла на GitHub (Render обновится сам).

КАК ЭТО РАБОТАЕТ
----------------
- Сайт шлёт пинг каждые 30 секунд: устройство, источник, отпечаток.
- Координаты летят ТОЛЬКО после согласия на геолокацию (шторка на сайте).
- Без согласия гость виден в списке, но без точки на карте.
- Админка обновляется каждые 5 секунд.
- Отпечаток переживает инкогнито: тот же человек не станет «новым гостем».

ОГРАНИЧЕНИЯ (честно)
--------------------
- Бесплатный Render «засыпает» без посетителей: первый заход на админку
  после паузы 30-60 секунд. Сайт на Netlify при этом работает всегда.
- История гостей живёт в памяти сервера: после его перезапуска список
  начинается заново. Для постоянной истории понадобится база данных.
- VPN + другой браузер + антифингерпринт = гостя не узнать (предел метода).

ПРОВЕРКА
--------
1) Откройте сайт, подождите 30 секунд.
2) Откройте админку — в списке должен появиться гость.
3) Нажмите «Разрешить геолокацию» на сайте — на карте запульсирует точка.
4) Откройте сайт в инкогнито — счётчик не должен вырасти вдвое.
